## Add a completed project

1. Create the project repository with a clear name.
2. Use [PROJECT_TEMPLATE.md](PROJECT_TEMPLATE.md) to write the README.
3. Add browsable source, a useful demo or screenshot, dependency/setup information, and evidence of validation.
4. Identify academic context or independent work and credit contributions accurately.
5. Add one row to the appropriate collection in [PORTFOLIO.md](PORTFOLIO.md).
6. Feature the project if it adds stronger evidence of business analysis, analytics, responsible AI, or working automation than an existing showcase entry.

Keep the featured collection selective. Replace weaker entries as stronger independent projects are completed.
